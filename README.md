# Robot Manager

Used by [W4Studica](https://github.com/W4Studica) on Studica VMX-pi (Raspberry Pi 4, Linux ARM64) to run WPILib 2027 C++ robot programs deployed through GradleRIO. Provides process supervision, RioLog, network configuration and VMX runtime helpers.
